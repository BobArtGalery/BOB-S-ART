# Bob’Art – galerie d’art éphémère (Genève)

Site vitrine responsive (HTML / CSS / JavaScript, sans framework) réalisé dans le cadre du projet de publication Web – Université Côte d’Azur.

## Pages
- `index.html` : accueil, carrousel, présentation, localisation (Google Maps)
- `oeuvres.html` : œuvres exposées
- `artistes.html` : présentation des artistes
- `contact.html` : coordonnées et réseaux sociaux
- `inscription.html` : formulaire d’inscription (contrôle de saisie, aucune donnée enregistrée)

## Structure
- `css/style.css` : feuille de style unique
- `js/script.js` : menu, carrousel, agrandissement des images, formulaire
- `images/` : visuels et logo

## Points d’attention
- Polices : Kameron (Google Fonts)
- Accessibilité : lien d’évitement, navigation clavier, `prefers-reduced-motion`
- SEO : titre et description uniques par page, données structurées, `robots.txt`, `sitemap.xml`
